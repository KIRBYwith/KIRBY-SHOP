# KIRBY-SHOP
KIRBY-SHOP is a virtual website created for penetration testing practice.   
KIRBY-SHOP은 모의해킹 프로젝트를 위해 가상으로 만든 웹사이트입니다.

아래 명령어 실행

npm install react react-dom react-scripts web-vitals lucide-react react-router-dom react-daum-postcode
